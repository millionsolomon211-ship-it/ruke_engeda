Tourism Booking System

A modern tourism booking platform that enables tourists to discover destinations categorized by region, create bookings, and manage favorite destinations.

The architecture follows a microservices approach:

Destination Service (Node.js & Express.js): Manages destination data, bookings, and user favorites.
Frontend & API Gateway (Next.js): Provides the user interface, authentication and authorization features, and acts as a reverse proxy that routes requests to backend services.

Key Features:

Destination browsing by region
User registration and authentication
Destination booking management
Favorite destination tracking
Microservice-based architecture
API Gateway pattern implementation
